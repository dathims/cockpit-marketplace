Privacy policy

Last updated: October 9, 2026

In short: Cockpit plugins run on your own computer. OXYGENE NUMERIQUE never receives, stores or sees your emails, calendar events, files or Google credentials. This website uses no cookies and no analytics.

1. Who we are

This policy covers the website plugin.usecockpit.co and the open source software published on it ("Cockpit plugins"), including the Google Multi-Account MCP server ("google-multi"). They are published by OXYGENE NUMERIQUE, SAS, 111 avenue Victor Hugo, 75016 Paris, France, RCS Paris 749 947 297. Contact for any privacy question: rudy@oxynum.fr.

2. This website

The website is a set of static pages hosted by GitHub Pages. It sets no cookies, loads no analytics, advertising or third-party scripts, and has no forms. As the hosting provider, GitHub processes standard technical logs (such as IP address, date and requested page) to deliver and secure the service, under its own privacy policy.

3. How google-multi works

google-multi is software you install and run on your own computer. It connects to Google APIs using an OAuth client that you create in your own Google Cloud project, and exposes tools to the AI assistant you choose to connect it to, such as Claude, Codex, Cursor or Gemini CLI.

There is no Cockpit server between Google and you. OXYGENE NUMERIQUE does not operate any backend for this software, does not collect telemetry, and has no technical way to access your data.

4. Google user data accessed

When you add a Google account, you grant the following permissions to your own OAuth client:

  • Basic profile (openid, email): your email address, used to label the account you connected.
  • Gmail (gmail.modify): read, search and label messages and threads, create drafts and send emails, when you ask your assistant to. It cannot permanently delete messages.
  • Google Calendar (calendar): list calendars and events, create, update and delete events, when you ask your assistant to.
  • Google Drive (drive.readonly): search files and read their content. Read only.

5. How Google user data is used

  • Google user data is used only to provide the features you request through your AI assistant: searching, reading, drafting, sending, scheduling.
  • When a tool runs, its result is returned on your computer to the AI assistant client you connected. That client may send it to its AI provider (for example Anthropic for Claude, OpenAI for Codex or Google for Gemini CLI) to answer your request. This transfer happens at your direction and is governed by that provider's terms and privacy policy.
  • Google user data is never sold, never used for advertising, and never used by OXYGENE NUMERIQUE to develop, improve or train artificial intelligence or machine learning models.
  • No human at OXYGENE NUMERIQUE reads your Google user data.

google-multi's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Storage and security

  • OAuth tokens are stored only on your computer, in ~/.config/google-multi-mcp, with file permissions restricting access to your user account.
  • Emails, events and files are processed in memory to answer a request. google-multi does not keep a copy of them on disk.
  • Sign-in uses OAuth 2.0 with PKCE and state verification. All connections to Google use HTTPS.

7. Retention and deletion

OXYGENE NUMERIQUE retains no Google user data. On your computer, tokens are kept until you remove them. To delete them, run npm run remove-account -- <alias> or delete the folder above. To revoke access on Google's side at any time, visit myaccount.google.com/permissions.

8. Sharing

We do not share Google user data with anyone, because we never receive it. The only transfer is the one described in section 5, to the AI assistant you choose, at your request.

9. Your rights

Under the GDPR you have rights of access, rectification, erasure, restriction, objection and portability. Since we hold no personal data from the software, most requests can be fulfilled directly on your computer as described above. For any question, write to rudy@oxynum.fr. You may also lodge a complaint with the CNIL (cnil.fr).

10. Children

Cockpit plugins are not directed to children under 16.

11. Changes

If this policy changes, the new version will be published on this page with a new date. Significant changes affecting Google user data will also be noted in the project repository.
